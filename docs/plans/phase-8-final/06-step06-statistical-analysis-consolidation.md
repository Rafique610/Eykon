# Phase 8 Step 06 — Statistical Analysis and Results Consolidation

## What

Apply the analysis plan from the Step 01 protocol, and build the final result
tables for the thesis:

- for every claim: the metric, the system value, the baseline value, the
  difference with a 95 % interval (Wilson for rates, bootstrap over questions
  or sessions for differences), worst session / worst case, and the verdict
  by the pre-registered rule;
- per category, per configuration, per phone tables;
- generalisation table: tuning vs earlier held-out vs final v3 for the main
  metrics (shows how much each stage of honesty cost);
- one-page "results at a glance" summary.

## Why

- The thesis's results chapter and the defense slides both need one
  consistent set of numbers. Consolidating in one place with one method avoids
  contradictions across chapters.
- Intervals and worst cases are required by the roadmap pessimist rules.

## How to implement

1. `src/benchmarks/final_report.py` producing all tables and plots from
   results files (no typed numbers).
2. Bootstrap resampling with numpy (already installed), fixed seed, number of
   resamples stated.
3. Review with the supervisor.

## Open decisions

- **Multiple comparisons.** Options: (a) report intervals only, no
  significance claims; (b) adjust for many comparisons (e.g. Holm correction)
  when claiming significance; (c) (a) plus (b) for the few main claims. Draft:
  (c).

## You test this

1. For each main claim, read its row and say whether the interval supports it.

## How this number could be lying

- Bootstrap over questions treats questions as independent although many come
  from the same session; also bootstrap over sessions for the main claims.
