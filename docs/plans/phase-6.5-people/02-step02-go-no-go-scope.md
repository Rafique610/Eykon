# Phase 6.5 Step 02 — Go / No-Go and Scope Freeze

## What

Decide whether this stretch phase runs, and in what form:

- **Inputs**: Step 01 approval status; Phase 6 results (are must-tier items
  done and stable?); time left before the defense (once known); availability
  of consenting participants.
- **Options**: (a) no-go — ethics design only, written as future work;
  (b) voices only — cross-session voice names (Steps 06, 08, 09);
  (c) faces and voices — all steps, within the 4-week time box.
- **Output**: `docs/results/phase-6.5/go-no-go.md` with the decision, the
  reasons, the time box start and end dates, and the steps in scope.

## Why

- Roadmap v2 §7 cuts faces first. A deliberate decision avoids drifting into
  a stretch feature while must-tier work is incomplete.
- A dated time box makes the hard scope limit real.

## How to implement

1. Checklist: Phase 6 exit criteria met? Phase 8 schedule realistic? Ethics
   approved? Participants available?
2. Decide with the supervisor; record.
3. Annotate the phase overview and each step doc with "in scope" or
   "out of scope".

## Open decisions

- The go / no-go option itself ((a), (b) or (c) above).

## You test this

1. Answer the checklist honestly. If any must-tier item is not done, the
   answer should usually be (a).

## How this number could be lying

- Optimism about remaining time; the decision uses the planned Phase 8
  schedule, not hopes.
